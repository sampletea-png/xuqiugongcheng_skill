# 扫描候选能力

读取 `.scratch/需求工程/<努力>/map.md` 的 `Destination`，只把它当作要看的那件工作。临时目的地不是功能过滤器。人没提到的寻常能力正是这次要找回来的。

查看同类产品和这件工作里已经常见的做法。只记录服务于这件工作的能力。另一件工作不要写进候选，交给 `capture-uncharted`。

覆盖写入 `.scratch/需求工程/<努力>/候选.md`：

```markdown
# 候选

- 能力 · 你提到了 / 你没提到 · 来源
```

来源要具体到产品或实践，不能只写「市场上有」。一条能力一行。不写全量功能表，不标优先级，不把候选写成需求。

扫完就停。分流交给 `place-candidate`，一次一项。
