# 重写目的地

只改 `.scratch/需求工程/<努力>/map.md` 的 `Destination`。

目的地仍然只有一件工作。把人已经接受、且服务于这件工作的能力写进完成标准。没被接受的候选、雾区里的行、未开图清单，都不写进目的地。

不编辑 `Notes`、`Decisions so far`、`Not yet specified`、`Out of scope`，不创建或关闭票。
