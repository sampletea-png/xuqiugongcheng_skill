# 更新雾区

一次只动 `.scratch/需求工程/<努力>/map.md` 的 `Not yet specified` 里的一行。

- 仍属于这件工作、但还说不成问题：追加一行。
- 这一行已经能写成问题，或人已明确放弃：删掉这一行。写票、写入范围之外或写入未开图，分别交给对应技能。

另一件工作不进雾区，交给 `capture-uncharted`。不因为一行被删掉就自动建票。
